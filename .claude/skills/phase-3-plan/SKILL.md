อ่าน docs/PLAN.md แล้วเสนอแผน "เฟส 3" ตามหัวข้อด้านล่าง เฟสนี้ให้วางแผนอย่างเดียว ยังไม่ต้องลงมือเขียนโค้ด

- **งบซ่อม:** แท็บ Budget และ KPI Cost Control บน Dashboard
- **แผน PM:** แท็บ PM_Plan ที่สร้างงาน Preventive อัตโนมัติตามรอบ เริ่มจากตารางเช็คปั๊มน้ำ Tahona ซึ่งเช็คทุก ธ.ค. / มี.ค. / มิ.ย.
- **งานซ่อมซ้ำ:** ตรวจงานที่เสียซ้ำภายใน 7 วัน (`is_repeat`, `related_job_id`) แล้วให้ Admin เป็นคนยืนยัน
- **ช่างประจำหมวด:** ใช้ `Categories.assignee_user_id` และทำ rich menu แยกตามบทบาท
- **คะแนน KPI:** คิดคะแนนตามเกณฑ์ในแท็บ KPI เดิม (คะแนน 5 / 4 / 3 / 2)

**สิ่งที่ต้องมีในแผน**

- แท็บและคอลัมน์ที่ต้องเพิ่ม
- action ใหม่
- ผลกระทบต่อโควตาข้อความ LINE
- เกณฑ์ผ่านของแต่ละหัวข้อ
