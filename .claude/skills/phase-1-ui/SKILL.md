## ขอบเขต

- **หน้า LIFF ตาม PLAN §9:**
    - `register.html`
    - `report.html`: ย่อรูปก่อนส่งไม่เกิน 4 รูป ส่งสำเร็จแล้วเรียก `liff.sendMessages` ด้วยเลขงาน
    - `job.html`: รับ, ปฏิเสธ, ส่งต่อช่างนอก, check-in, ปิดงาน (อะไหล่ + รูป After + ไม่มีคนอยู่หน้างาน), รับทราบ
    - `jobs.html`
    - `admin.html`: เฉพาะจ่ายงานใหม่และเลือกช่างนอก
- **ไฟล์ JS ร่วม:** `js/liff.js`, `js/api.js`, `js/image.js`, `js/ui.js`
- **หน้าตา:** UI ภาษาไทย เรียบง่าย ปุ่มใหญ่ ใช้ง่ายบนมือถือ และมีสถานะกำลังโหลดกับข้อความ error ที่อ่านเข้าใจ
- **Rich menu:** บอกขั้นตอนตั้งค่าตาม docs/SETUP.md ข้อ D

- [ ] ช่างอาคาร (TECH) ได้การ์ดงาน กดรับแล้วสถานะเป็น ACCEPTED

- [ ] ช่างปฏิเสธพร้อมเหตุผล พี่แตงกวาได้แจ้งเตือน และจ่ายงานใหม่จากหน้า admin ได้
