# REQUIREMENTS: สิ่งที่ผู้ใช้ต้องการ

**แหล่งที่มา**

- เสียงคุยระหว่างพี่แตงกวา (Admin งานซ่อม) กับ AOF ขณะไล่ดูแท็บ System ในไฟล์ Maintenance List ถอดเสียงเมื่อ 29 ต.ค. 2026
- ไฟล์ Maintenance List: แท็บ System, KPI, supplier และแท็บของแต่ละร้าน
- Flow 6 ขั้นที่ AOF วางไว้

## Flow หลัก (AOF)

1. แจ้งปัญหา แล้วเก็บข้อมูล
2. แจ้งเตือนผ่าน LINE OA ให้ช่างกดรับหรือปฏิเสธ
3. เมื่อช่างกดรับ เก็บข้อมูลลง Google Sheet
4. เมื่องานเสร็จ แจ้งกลับไปหาคนแจ้งผ่าน LINE OA
5. ข้อมูลใน Google Sheet อัปเดต
6. นำข้อมูลไปทำ Dashboard

## คำถามที่ยังเปิด และค่าเริ่มต้นระหว่างรอคำตอบ

ระหว่างที่ยังไม่ได้คำตอบ ระบบใช้ค่าเริ่มต้นในตาราง และค่าทุกตัวแก้ได้โดยไม่ต้องแก้โค้ด ยกเว้นข้อที่ระบุว่าแก้ที่โค้ด
